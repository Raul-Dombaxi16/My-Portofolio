## 🚀 Competências técnicas

### Desenvolvimento Front-end

- **HTML5:** estruturação semântica de páginas web, formulários e organização de conteúdo.
- **CSS3:** estilização de interfaces, layouts, Flexbox, Grid e desenvolvimento de páginas responsivas.
