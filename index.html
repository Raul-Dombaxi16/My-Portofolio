UM POUCO SOBRE MIM

Sobre mim

Sou estudante e desenvolvedor web em formação. O meu interesse pela tecnologia começou ainda durante o ensino médio, no Complexo Escolar Quineus, e desde então tenho procurado aprender através da prática.

Atualmente, trabalho com HTML, CSS e JavaScript, criando páginas e pequenas aplicações web. Também estou a melhorar a minha utilização do Git e GitHub para organizar e acompanhar os meus projetos.

O meu objetivo é continuar a evoluir como programador, construir soluções úteis e, futuramente, tornar-me um desenvolvedor Full Stack.
